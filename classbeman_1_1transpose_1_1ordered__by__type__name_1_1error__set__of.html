Detailed Description

template<class... ERRORS>
class beman::transpose::ordered_by_type_name::error_set_of< ERRORS >

The set of error types a computation may raise, at a canonical pack.

Write error_set<...> rather than naming this template directly: the alias canonicalizes, this template only accepts an already-canonical pack.

VALUE-LEVEL INVARIANT: a non-empty witnessed subset of {ERRORS...} – for each raised type, at most one witness.
