Detailed Description

template<class T>
class beman::tree_algorithms::BinaryTree< T >

Persistent binary tree where every node carries a value.

Nodes are either leaves (no children) or internal nodes with left and right subtrees. Sharing is structural: subtrees are held by shared_ptr, so copies are cheap and the tree is immutable once built.
