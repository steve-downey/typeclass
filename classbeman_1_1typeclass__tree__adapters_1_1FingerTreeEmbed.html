Detailed Description

template<typename TREE>
class beman::typeclass_tree_adapters::FingerTreeEmbed< TREE >

Embedding for unfold_with: rebuilds one layer in the tree's own representation, under one allocator and one monoid instance.

Every node is constructed by the tree's structural builder, which computes its cached measure, so a tree an unfold builds satisfies the measure invariant by construction.

Preconditions, which the layers of a well-formed finger tree satisfy and a hand-written coalgebra must: every engaged position holds the sort its place requires (elements in a Single, in digits and under nodes; a tree in a Deep's spine); a Single's element and every digit are engaged; digits hold one to four elements of one height; a Deep's spine is one level below its digits; a node's children have one height.
