Detailed Description

template<typename TREE>
class beman::fingertree::tree::FingerTreeStructureBuilder< TREE >

Constructs the real forms of a finger tree under one allocator and one monoid instance, computing every cached measure as it goes.

The parts combined by one builder must share its configuration: built by it, by an equal builder, or read from a tree with an equal allocator and the same measure law. A cached measure is valid only under the monoid that computed it; the builder cannot check that, so it is a precondition.

A Deep of left, spine, then right.

Preconditions: each digit holds one to four nodes; every node of both digits has one height h; spine is empty or is at level h + 1 and was allocated by an equal allocator. An empty spine is stored as no spine, which is the representation's own form.
