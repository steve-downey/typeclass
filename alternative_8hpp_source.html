19// EVIDENCE, NOT PROPOSED WORDING. D3200R0 does not propose an Alternative
20// abstraction -- deferred, not rejected, on the same footing as Monad. The
21// disjunction's semantics were decided before the typeclass was written
22// (docs/transpose/decisions.md#alternative-disjunction-semantics), and this
23// header is the proof that the mechanism carries them: `alt(a, b, ...)`
24// yields the leftmost operand that holds a value; the value side is the
25// common type or the `variant` join of the operands' value types, in operand
26// order, never read as a grade; the error side fails only when every operand
27// fails and then carries every operand's evidence at the join of their
28// grades; an operand that cannot fail makes the disjunction total; and
29// `zero<C>()` is the identity where the context has one. It is unproposed
30// only because nothing in the coordinated set calls `alt`.
31//
32// The basis is `alt`, n-ary. It is not derived from a binary `alt` by
33// folding, because folding nests the value join -- `variant<variant<A, B>,
34// C>` where `variant<A, B, C>` is meant -- and the instance is the only
35// place that knows all of its operands at once. `zero` is a basis operation
36// where the context's failure state carries no witness (`optional`), and
37// absent where it needs one (`expected`): a context without `zero` is a
38// disjunction without an identity, which is a semigroup, and the laws that
39// mention `zero` are vacuous for it rather than false.

194// -- Operation objects --
195//
196// See functor.hpp for the shape and the motivation. `alt` deduces its context
197// from the first operand, as `invoke` does; `zero<C>()` is spelled in
198// apply.hpp beside `pure<C>` and `raise<C>`, because it builds a context and
199// must name it (docs/transpose/decisions.md#failure-injection-spelling), and
200// dispatches to the applicative object, which is where an instance's `zero`
201// is declared first.

218 requires requires {
219 TC.alt(std::declval<FIRST>(), std::declval<REST>()...);
220 }
221 [[nodiscard]] constexpr auto operator()(FIRST &&first, REST &&...rest) const
222 noexcept(noexcept(TC.alt(std::forward<FIRST>(first),
223 std::forward<REST>(rest)...))) {
224 return TC.alt(std::forward<FIRST>(first), std::forward<REST>(rest)...);
