Detailed Description

template<class TREE>
class beman::fingertree::finger_tree_concat_monoid< TREE >

Concatenation under a selected configuration.

Operands belong to the prototype's measure-law domain. Both are rebuilt under its allocator and monoid, so cached measures and foreign resources never leak into the result. O(n + m); copying payloads is required for this explicit rebuild.
