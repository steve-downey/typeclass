Detailed Description

template<class Impl>
struct beman::transpose::derive_foldable< Impl >

CRTP base for Foldable instances.

Impl must provide either fold_map(f, container, monoid) or fold_right + element_type; all other operations are derived from whichever is the primitive. Declaring element_type additionally unlocks the derived operations that must name the element type: the two-argument fold_map, combine_all and fold without an instance, to_vector and find_first.

Every operation carries a computed exception specification: that of the route it takes, spelled from the same requires-expression the body selects the route by, with the derived route asked through the probe the constraint names (docs/transpose/decisions.md#operation-noexcept). The derived fold_left and fold_right are never noexcept, because the programs they compose are std::functions.

Collects all elements into a std::vector in traversal order.

The derivation folds under a concatenation monoid over std::vector of the element type, so it needs that type: it is available where Impl declares element_type. The monoid is this header's own, not the registered Monoid<std::vector<T>>, which is declared with the vector instances (docs/transpose/decisions.md#instance-placement).
