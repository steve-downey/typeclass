Detailed Description

template<typename T, typename MONOID>
class beman::fingertree::tree::FingerTreeNode< T, MONOID >

One element of a finger tree: a Leaf holding a payload, or a Node2 or Node3 of nodes one lower.

Owns a share of the immutable element, so a node stays valid for as long as it exists.

MONOIDthe monoid instance type the cached measure was computed under
