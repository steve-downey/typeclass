Detailed Description

template<class T>
struct beman::transpose::ZipListApplicativeImpl< T >

Applicative typeclass instance for zip_list<T> with positional (zip) semantics.

pure(x) = infinite repetition of x (zip_list::repeat(x)). invoke(f, xs...) zips the argument lists positionally under the plain function f, truncating to the length of the shortest finite operand. If all operands are infinite the result is also infinite.

The callable is decay-copied (moved, for an rvalue) and the copy is what runs, so a caller whose callable carries state it needs to see afterward passes std::ref(f). That is the Standard's rule for its own algorithms ([algorithms.requirements]), and the constraint states the copy, so a callable that cannot be copied from the argument given fails softly. So do a callable that cannot take one element of each operand, and one whose result a zip_list cannot hold.
