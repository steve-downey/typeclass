Detailed Description

template<typename PAYLOAD_TYPE>
struct beman::fingertree::tree::IntervalMeasure< PAYLOAD_TYPE >

Measure policy: an interval measures its end point.

Under max_monoid<std::size_t> the cached measure of any subtree is its maximum end point, which is what lets a query skip a subtree whole. The measure value type is a plain std::size_t; the monoid is chosen by the tree's instance type, not by wrapping the value.
