Detailed Description

template<class Impl>
struct beman::transpose::derive_alternative< Impl >

CRTP base for Alternative instances.

Impl must provide the n-ary alt(first, rest...), and provides zero() where the context's failure state carries no witness. Nothing is derived from the basis today; the base exists so that the lookup, the object concept and the operation objects have the shape every other typeclass has, and so that an instance's alt is reached the same way its bind or invoke is. Derived operations – a guard, a fold of a range of contexts under alt – wait for the client that calls them.
