Detailed Description

template<class T>
struct beman::transpose::zip_list< T >

List with positional (zip) applicative semantics that can represent an infinite repetition of a single value.

A zip_list is either finite (elements stored in data) or infinite (a single repeated value that logically occupies every position). The ZipList applicative applies functions positionally and truncates to the shortest finite operand; pure(x) yields the infinite repetition of x so that it acts as an identity for truncation.

Invariant: when repeated has a value, data is ignored and the zip_list models an infinite repetition of repeated.
