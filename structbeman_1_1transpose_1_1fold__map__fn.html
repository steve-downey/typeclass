Detailed Description

Operation object for Foldable's fold_map primitive.

The container type keys the lookup and is deduced from the second argument. The monoid instance is the trailing argument, as it is on the instance (docs/transpose/decisions.mdmonoid-selection); without it the call defaults to the registered Monoid of the result type, and where that type has no registration the two-argument form is not a candidate.
