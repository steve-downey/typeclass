Detailed Description

Folds one ExprF layer elementwise: the elements of an expression tree are the constants, so Const maps its value and Add/Mul just combine their children's results.

Note the contrast with eval_algebra: an elementwise fold sees the constants through one combine, where evaluation interprets each alternative — summing the constants of (1 + 2) * 3 gives 6, evaluating it gives 9. ExprF has no empty alternative, so the identity goes unused.
